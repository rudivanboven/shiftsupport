# ShiftSupport App

Initial Next.js UI rebuild for ShiftSupport.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Structure
- `app/page.tsx` = homepage composer/import file
- `components/home/...` = one folder per homepage section
- each section folder contains a `.tsx` file and a `.module.css` file
- images are intentionally dummy placeholders
- Supabase/auth/functionality is intentionally not connected yet
